🔎 Browser Data Scanners

Use these bookmarklets on the page or app you plan to embed in the main pane. They report the element IDs and local storage keys you can feed into your config.json.

🆔 ID Scanner

Scans every element with an id on the current page and downloads a CSV of ID / value / type / tag. Use the IDs from this report as your targetIds.

🆔 Scan page IDs
Drag this button to your bookmarks bar, open the target page, then click the bookmark.

💾 Local Storage Scanner

Reads every key in the page's localStorage and downloads a CSV. Use the keys you need as your targetLocalStorageKeys.

💾 Scan local storage
Local storage is origin-scoped — run it on the exact site you are wrapping.

How to install a bookmarklet

  1. Make sure your browser's bookmarks bar is visible (Ctrl/Cmd + Shift + B).
  2. Drag the button above onto the bookmarks bar.
  3. Navigate to the target page and click the new bookmark.
  4. Approve the CSV download and open it in a spreadsheet.
If dragging does not work, right-click the bookmarks bar → “Add page” and paste the bookmarklet source shown below into the URL field.

These tools run entirely in your browser and never transmit page data anywhere.
