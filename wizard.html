Power App Desktop Extension

Configuration Wizard — build your config.json in a minute.

1 Connect your Power App

Paste the play URL of the Power App you want to wrap. You can copy it from the Power Apps “Share” dialog or your browser’s address bar.

The base URL. Any query parameters already on it are preserved.
The web page the main pane opens to at launch.

2 Choose what context to send

The main pane is scraped and the captured values are appended to the Power App URL. Use the data scanners to find element IDs and local storage keys on your target site.

One ID per line (commas also work).
One key per line. Keep this list small — values travel in the URL.

3 Pick your triggers

Triggers decide when the Power App is refreshed with fresh context.

Recommended: 2000 (2 seconds).

4 Save into your project

Click save, then pick your downloaded/cloned repo folder. The wizard writes config.json straight into it — no manual editing or unzipping required.

✅ Saved! Now run these commands from your project folder:

# 1. Install dependencies
$ npm install
# 2. Test your desktop app locally
$ npm start
# 3. Build a distributable installer
$ npm run make
